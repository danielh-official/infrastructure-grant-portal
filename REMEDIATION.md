# Remediation evidence

Copy this section for each finding you work on.

## Finding ID and short title

| Item | Evidence |
| --- | --- |
| Reproduction | Browser, viewport, input method, and steps |
| User impact | What the applicant cannot do or understand |
| Expected result | What the applicant should be able to do |
| Changes | Code paths affected and why |
| Automated verification | Test command or case and observed result |
| Manual verification | Keyboard and screen reader observations, with versions |
| Regression checks | Native form, JSON API, and any shared UI you affected |
| Review status | Open, ready for consultant retest, or accepted |
